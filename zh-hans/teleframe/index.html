放在哪里都行的录制框

在控制栏里选择形状：16:9 适合 YouTube，9:16 适合 Reels、TikTok 和 Shorts，也可以选 1:1、4:3、4:5、21:9、自由形状或整个显示器。

拖动一角即可调整大小，比例保持不变。录制时也可以移动录制框，视频画面会跟着它走。

暂停，删掉录坏的片段，保存

每次从 REC 到暂停之间录下的内容都是一个片段。说错了？删掉最后一个片段，重新录一遍。

按下停止后，Teleframe 会在几秒内把所有片段合并成一个 MP4。视频按原样复制，不会重新编码。

控件排成细细的一行，位于录制框下方。想让屏幕干净一些时，可以把它们收成一个按钮。

常见问题

有免费试用吗？

有。下载 Teleframe，7 天内免费使用全部功能。试用期结束后，输入许可证密钥即可继续录制。

许可证密钥怎么用？

购买后，你会收到一个以 TELE- 开头的密钥。在 Teleframe 里点击齿轮图标，选择 LICENSE，然后粘贴密钥。一个密钥最多可用于 3 台电脑。激活时需要联网一次，之后 Teleframe 可以离线使用。

Teleframe 是订阅制吗？

不是。只需付一次钱，下载的软件一直归你所有。也不用注册账号。

Teleframe 会加水印吗？

不会。视频里只有录制框内的内容，别的什么都没有。

能录声音吗？

能。在设置里选择系统声音、麦克风，或两者混合。声音保存为 192 kbps 的 AAC，每分钟约 1.4 MB。

能用电脑录屏做 TikTok、Reels 和 Shorts 的竖屏视频吗？

能。选择 9:16，录制框就会变成竖长的矩形。把它放到你想录的屏幕区域上，按 REC 即可。

录像保存在哪里？

保存在你在设置里选择的文件夹，默认是 Videos\Teleframe。每段录像都是一个以日期和时间命名的 MP4。

文件有多大？

这取决于录制框的大小和画质设置。在 HIGH、60 fps 下，一分钟 1080p 视频约 113 MB。开始录制前，设置里会显示当前录制框的预估大小。

Windows 提示“已保护你的电脑”，怎么办？

安装程序没有代码签名，所以第一次运行时 Windows SmartScreen 可能会发出警告。点击“更多信息”，再点击“仍要运行”。

Teleframe 能在 Mac 上用吗？

不能。Teleframe 支持 64 位 Windows 10（2004 或更高版本）和 Windows 11。

打开 下载页面 并输入你付款时用的邮箱。密钥会重新发送到这个地址。
