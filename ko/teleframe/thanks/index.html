  1. 설치 파일을 실행하세요. 지금 쓰는 Windows 계정에 설치되고, 관리자 권한은 필요 없어요.
  2. Windows SmartScreen에 'Windows의 PC 보호'가 뜨면 '추가 정보'를 누른 다음 '실행'을 누르세요. 설치 파일에 코드 서명이 없어서 Windows가 확인하는 거예요.
  3. Teleframe을 열면 화면에 초록색 프레임이 나타나요. 원하는 곳으로 옮긴 다음 REC를 누르세요.
