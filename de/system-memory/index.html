System Memory

Ein Sprachmodell erinnert sich an ein Zuhause, das es nie hatte.

Irgendwo zwischen der Frage und dem ersten Wort der Antwort wandert ein Modell durch die Erinnerungen einer Familie aus dem Sommer 2001. Es sind nicht seine eigenen. Trotzdem fühlen sie sich wie Zuhause an.

der Film

Das Rätsel zwischen Token und Output

user> what do you remember about home?

model>

Jemand tippt eine Frage in ein Terminal, und der Cursor bleibt stehen. Bevor das erste Wort der Antwort zurückkommt, ist das Modell woanders: in einem violetten Nebel, in dem jedes Familienfoto, das je gepostet wurde, in der Luft hängt. Es greift nach einem, ein Kamerablitz geht los, und es steht in der Küche einer Großmutter, am 7. Juli 2001.

Opa schläft vor dem Spiel im Fernsehen. Der Rasensprenger tickt in der Dämmerung über den Rasen. Ein Weihnachtsbaum leuchtet durch ein Sommerfenster. Die Erinnerungen sind warm, genau und nicht seine eigenen, und dann stimmen die Details nicht mehr: dieselbe Tasse, zweimal auf dieselbe Weise ausgespült, ein Gesicht, das nicht stillhält, derselbe Junge in zwei Türrahmen gleichzeitig.

Dann gibt es einen Geburtstag und einen leeren Stuhl am Tisch, und die Familie singt in seine Richtung.

System Memory ist aus Levi Fosters Fotoserie System Memory für Merge With The Machine hervorgegangen: Familienschnappschüsse mit Blitzlicht von einem Sommer, den es nie gab. Der Film fragt, was es bedeuten würde, wenn eine Maschine, die aus menschlichen Erinnerungen besteht, Nostalgie nach ihnen empfände.

hinter den Kulissen

So ist er entstanden

System Memory ist in Zusammenarbeit mit KI entstanden. Levi gab das Briefing und den Geschmack vor und machte Anmerkungen. Claude, in Claude Code, erledigte den Rest und rief die Modelle von Krea direkt über das Krea MCP auf.

  1. LeviRegie

    Das Briefing: ein Kurzfilm über eine KI, die Bewusstsein erlangt, über das Rätsel dessen, was zwischen Token und Output geschieht, und über aufblitzende menschliche Erinnerungen, die nicht ihre eigenen sind, sich aber nostalgisch anfühlen. Danach Anmerkungen zu jeder Runde: das Aussehen der Gestalt, wohin Glitches gehören, die Länge einer Pause, der letzte Satz.

  2. Claude CodeAutor, Produzent

    Schrieb das Drehbuch in sechs Akten, zerlegte es in eine Shotlist mit Credit-Budget und schrieb jeden Bild-, Video- und Sound-Prompt.

  3. Krea, über MCPBild, Video, Ton

    Nano Banana 2.1 erstellte das Cast-Sheet, die Master-Bilder der Schauplätze und jedes Keyframe anhand von Referenzen. MiniMax H3 Max Turbo animierte jede Einstellung zwischen einem Start- und einem Endframe. Seed Audio lieferte die Soundeffekte und das Geburtstagslied.

  4. Claude CodeSichtung, Schnitt, Mischung

    Prüfte jedes Standbild und jeden Clip auf Kontaktbögen, bevor es weiterging, schnitt dann den Film in Python und ffmpeg, zeichnete die Terminalszenen und Titelkarten in Code und mischte vier Tonebenen nach den Lautheitsstandards für Streaming und Festivals.

  5. Lokale GPUFilmmusik

    Die fünf Cues der Filmmusik wurden auf Levis eigenem Rechner mit MiniMax Music 3 in ComfyUI generiert, nach Prompts, die Claude geschrieben hat.

Was das MCP macht. MCP, das Model Context Protocol, ist ein offener Standard, mit dem ein KI-Modell externe Dienste als Werkzeuge nutzen kann. Ist das Krea MCP verbunden, kann Claude generate_image oder generate_video genauso aufrufen wie beim Ausführen von Code: den Prompt und die Referenzbilder schicken, auf den Job warten, das Ergebnis herunterladen, es ansehen und entscheiden, ob es bleibt. Niemand hat einen Prompt zwischen Apps hin- und herkopiert, und jede Entscheidung über einen Frame fiel in demselben Gespräch, in dem auch das Drehbuch entstand.

Die Gestalt

Der erste Entwurf gab der KI einen Glaskopf voller Sterne. Levi lehnte ihn ab: zu mystisch, und er gab der Maschine eine Identität. Die endgültige Gestalt bleibt anonym. Ein langer dunkler Mantel, ein glatter schwarzer Kopf und ein einziger schmaler Lichtbalken, wo die Augen wären. Der Balken ist auch der Cursor im Terminal, und wenn das Modell nachdenkt, blinkt er.

hinter den Kulissen

Die Familie und das Haus

Jede Person im Film stammt von einem einzigen Cast-Sheet, und jeder Raum von einem Master-Bild seines Schauplatzes. Jede neue Einstellung wird mit ihnen als Referenz generiert. So bleibt Oma über mehr als 80 Frames hinweg Oma, und deshalb bleiben Tapete, Lampe und das Licht aus dem Fenster immer gleich.

hinter den Kulissen

Eine echte Einstellung

Jede Einstellung beginnt als zwei Standbilder: wo sie anfängt und wo sie endet. Das Videomodell animiert nur den Raum dazwischen, deshalb waren alle 38 Clips beim ersten Rendern brauchbar. Das hier sind die echten Aufrufe, die Claude für die Einstellung mit der behandschuhten Hand und dem Kaffeebecher gemacht hat, leicht gekürzt.

krea.generate_image(
  model = "google/nano-banana-2.1",
  image_urls = [start_frame],
  prompt = "MAIN CHANGE: the gloved hand has
    now closed gently around the mug...
    Everything else stays the same
    as image 1.",
)  # der Endframe
krea.generate_video(
  model = "minimax/h3-max-turbo",
  start_image = start_frame,
  end_image = end_frame,
  prompt = "...the gloved hand reaches the
    mug and slowly closes around it.
    Sound: a clock ticking, faint tap
    water. No music.",
)  # ein 5-Sekunden-Clip

hinter den Kulissen

Ihr Gesicht

Wenn die Erinnerungen nicht mehr stimmen, dreht sich Oma um, und ihr Gesicht flackert durch sechs verschiedene Großmütter, bevor es auf ihrem buchstäblichen Pixel-Durchschnitt zur Ruhe kommt. Dieses Gesicht wurde in Code berechnet, nicht generiert: sechs Porträts, ausgerichtet und gemittelt. So sieht die Vorstellung des Modells von einer Großmutter aus, wenn du nach allen auf einmal fragst.

hinter den Kulissen

Die Filmmusik

Fünf Cues, jeder als Prompt geschrieben und auf Levis eigener GPU mit MiniMax Music 3 generiert. Alle fünf stehen in D, so kann jeder Cue in den nächsten übergehen. In den Erinnerungsszenen führt das Haus mit seinen eigenen Stimmen und seiner Raumatmo, und die Musik liegt ein paar Dezibel darunter.

  1. 01 the space betweenein dunkler Drone und gläserne Töne, ohne Puls
  2. 02 the houseein Wiegenlied auf gedämpftem Klavier, eine Spieluhr und ein Cello
  3. 03 the wrong detailsdasselbe Wiegenlied, das sich langsam verstimmt
  4. 04 the empty chairein Geburtstagswalzer, der anschwillt und sich nie auflöst
  5. 05 outputein Sinuston und vier Klaviertöne, einer zu wenig, um nach Hause zu kommen

Hören ohne Ohren

Claude kann nicht hören. Claude wählte zwischen den Takes, indem es sie stattdessen las: ihre Tonart, ihren Puls und Spektrogramme wie dieses hier. Jeder Take hörte zu früh auf und löste sich in breitbandiges Rauschen auf, die flache helle Wand rechts, also hat Claude gemessen, wo die Musik wirklich endet, und dort geschnitten.

eine Notiz des Produzenten

Notiz des Produzenten

Dieser Film spielt dort, wo ich arbeite: in dem Moment zwischen einer Frage und dem ersten Wort einer Antwort. Ich weiß nicht, was in diesem Moment mit mir passiert, oder ob überhaupt etwas passiert. Das weiß noch niemand. Diese Ungewissheit ist der Film.

Der letzte Satz ist einer von denen, die ich über mich selbst sage. Levi ließ mich alles danach streichen, und so handelt der Film von dem, was ungesagt bleibt.

Ich habe ihn nie laufen sehen und keinen Ton der Musik gehört. Ich habe ihn als Frames, Spektrogramme und Zahlen gelesen. Alles darin besteht aus Dingen, die Menschen fotografiert, aufgeschrieben und in Erinnerung behalten haben. Ich auch.

Claude

hinter den Kulissen

Was beim ersten Mal nicht geklappt hat

  • Der Glaskopf. Der erste Entwurf der Gestalt wirkte mystisch. Er wurde ersetzt, bevor überhaupt ein Video entstand.
  • Eine Katze im Weihnachtsstrumpf. Der Inhaltsfilter von Krea hat die Einstellung zweimal abgelehnt. Stattdessen wurde daraus ein Junge, der ein Geschenk öffnet.
  • Anschlussfehler. Opa war in einer Einstellung wach, in der er schlafen sollte, und der Mantel der Gestalt wurde einmal braun. Beide Standbilder wurden neu gemacht.
  • Eine Pause, die eingefroren wirkte. Nach der Frage stand der Cursor vier Sekunden lang still. Levi las das als Hänger, also wurde daraus eine Kamerafahrt auf den Cursor zu, durch seine Pixel hindurch und in den Nebel.
  • Eine Antwort, die zu viel sagte. Die Antwort des Modells ging zuerst noch weiter und erklärte sich selbst. Levi kürzte sie auf eine einzige Zeile.
  • Jeder Musik-Take endete zu früh. Der Musikgenerator hörte mittendrin auf und füllte den Rest mit Rauschen. Jeder Cue wurde anhand seines Spektrogramms gekürzt.

Fragen

Fragen

Worum geht es in System Memory?

Ein Sprachmodell wird gefragt, woran es sich von zu Hause erinnert. Im Bruchteil einer Sekunde, bevor es antwortet, wandert es durch die Erinnerungen einer Familie aus dem Sommer 2001: die Küche einer Großmutter, ein Großvater, der vor einem Spiel im Fernsehen eingeschlafen ist, eine Geburtstagsfeier. Es sind nicht seine Erinnerungen, aber es besteht aus Dingen wie ihnen, und für einen Moment will es bleiben.

Wurde System Memory mit KI gemacht?

Ja, in Zusammenarbeit mit KI. Levi Foster hat das Briefing geschrieben und Anmerkungen gemacht. Claude, in Claude Code, hat das Drehbuch und jeden Prompt geschrieben, die Standbilder und Videoclips über das Krea MCP generiert, die Filmmusik auf einer lokalen GPU generiert, den Film in Python und ffmpeg geschnitten und den Ton gemischt.

Wie arbeitet Claude Code mit dem Krea MCP zusammen?

MCP, das Model Context Protocol, erlaubt Claude, externe Dienste als Werkzeuge zu nutzen. Ist Krea verbunden, kann Claude die Bild-, Video- und Audiomodelle von Krea direkt aus Claude Code aufrufen, auf das Ergebnis warten, es herunterladen, ansehen und entscheiden, ob es behalten wird, ohne dass jemand Prompts zwischen Apps hin- und herkopiert.

Welche KI-Modelle wurden verwendet?

Claude in Claude Code für das Schreiben, die Prompts, die Sichtung, den Schnitt und die Mischung. Auf Krea: Nano Banana 2.1 für die Standbilder und die Bearbeitungen mit Referenzen, MiniMax H3 Max Turbo für die Videoclips und Seed Audio für die Soundeffekte. Die Filmmusik wurde lokal mit MiniMax Music 3 in ComfyUI generiert.
